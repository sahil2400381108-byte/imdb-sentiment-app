TRAIN ONCE. LOAD TO PREDICT.

From dataset to saved pipeline

random_state = 42
01

Validate & split

Inspect records, labels and normalized duplicates. Create a stratified 80/20 split before fitting any features.

02

Preserve the meaning

Decode HTML, remove tags and URLs, normalize case and whitespace. Keep negations such as “not” and “never.”

03

Learn from training text

Fit TF-IDF only on training reviews, then train Linear SVM on the sparse feature vectors. No test-set tuning.

04

Evaluate & save

Transform the untouched test data, measure predictions, and save the complete pipeline. The app loads it without retraining.

One consistent preprocessing pipeline for training and prediction. The test set never teaches the model its vocabulary or IDF weights.
